## ✨ Imkoniyatlar va Funksiyalar

1. **🤖 3 xil AI qiyinlik darajalari:**
   - 🟢 **O‘rtacha (50% AI):** Yangi o‘rganuvchilar uchun qulay, ba'zida xatolar qiladi.
